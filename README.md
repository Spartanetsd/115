# СЛОВО 115

«Твій голос. Твоя впевненість».

Вебзастосунок для підготовки до усної частини іспиту з української мови: 115 тем, монологи рівня С1, тренування з таймером, режим іспиту та мовний тренажер. Працює на iPhone, Android і комп’ютері, після першого завантаження — без інтернету.

## Що всередині

- **Вивчити** — до кожної з 115 тем: формулювання, суть, зміст цитати чи метафори, план із 5 пунктів, монолог на 2–3 хв, коротка версія на 1 хв, 5 тез, корисні слова, типові помилки, 3 додаткові запитання, приклад із життя, озвучування.
- **Тренування** — 30 с підготовки з опорними пунктами, 3 хв відповіді, запис голосу (якщо браузер підтримує), текст відповіді, локальний аналіз за прозорими правилами, самооцінка, порівняння зі зразком, кнопка «Скопіювати для перевірки в Claude».
- **Іспит** — випадкова тема з усіх 115 (або лише зі складних і невивчених), без підказок; зразок відкривається тільки після завершення спроби.
- **Говори правильно** — кальки, прийменники, «це не помилка», наголоси, милозвучність, пароніми, логічні зв’язки, слова-паразити, висновок. Є режим «Перевір себе».
- Інтервальне повторення, статуси «Не знаю / Вчу / Знаю / Впевнено», обране, пошук, фільтри, тема дня, плани на 7/14/30 днів, навантаження 10/20/30 хв, історія, експорт та імпорт JSON, скидання прогресу.

Застосунок не оцінює вимову, наголоси й інтонацію і не імітує експертної перевірки. Прогрес, записи голосу й тексти відповідей залишаються на пристрої.

## Публікація на GitHub Pages

1. Увійдіть на github.com і натисніть **New repository**. Назва — наприклад, `slovo115`. Тип — **Public**. Натисніть **Create repository**.
2. На сторінці репозиторію оберіть **Add file → Upload files**. Розпакуйте архів і перетягніть у вікно **весь вміст** папки `slovo115` (файли `index.html`, `style.css`, `app.js`, `manifest.webmanifest`, `service-worker.js`, `.nojekyll`, `README.md` і папки `data`, `assets`). Натисніть **Commit changes**.
   - Файл `.nojekyll` прихований у деяких системах. Якщо він не завантажився, створіть його через **Add file → Create new file** з назвою `.nojekyll` і порожнім вмістом.
3. Відкрийте **Settings → Pages**.
4. У полі **Source** оберіть **Deploy from a branch**.
5. Оберіть гілку **main** і каталог **/(root)**.
6. Натисніть **Save**.
7. За 1–3 хвилини вгорі сторінки з’явиться адреса на кшталт `https://ваш-логін.github.io/slovo115/`. Відкрийте її.
8. **Встановлення на iPhone:** відкрийте адресу в Safari → кнопка «Поділитися» → «На початковий екран» → «Додати». На Android у Chrome: меню ⋮ → «Встановити застосунок» або «Додати на головний екран».

Усі шляхи відносні, тому застосунок працює і в корені домену, і за адресою `/назва-репозиторію/`. Домен, платний хостинг чи сервер не потрібні.

## Як оновити застосунок

1. Змініть потрібні файли (наприклад, текст теми в `data/content-0N.js`).
2. Відкрийте `service-worker.js` і збільште версію в рядку `const VERSION = 'slovo115-v1.0.0';` — наприклад, на `v1.0.1`. **Це обов’язково**, інакше пристрої й далі показуватимуть збережену офлайн-копію.
3. Завантажте змінені файли в репозиторій (**Add file → Upload files**, ті самі назви замінять старі).
4. Після публікації користувачі побачать повідомлення «Доступна нова версія» → «Оновити зараз». Прогрес не губиться.

## Структура

```
index.html              головна сторінка
style.css               оформлення (світла й темна теми)
app.js                  логіка: маршрути, прогрес, таймери, запис, аналіз
data/content-01…08.js   навчальні матеріали (теми 1–15, 16–30, …, 106–115)
data/topics.js          каталог 115 тем, категорії, об’єднання даних, перевірка цілісності
data/lang.js            «Говори правильно» та правила аналізу тексту
manifest.webmanifest    опис PWA
service-worker.js       офлайн-кешування
assets/                 іконки
.nojekyll               вимикає обробку Jekyll на GitHub Pages
```

Без бібліотек і без збирання: файли можна редагувати в будь-якому текстовому редакторі.

## Перевірка цілісності

Під час кожного запуску `data/topics.js` перевіряє: рівно 115 тем, унікальні ID 1–115, категорія в кожної теми, повний навчальний комплект (суть, план із 5 пунктів, монолог, коротка версія, 5 тез, слова, помилки, 3 запитання, приклад, пояснення цитати для цитатних тем), відсутність заглушок. Результат — у **Налаштуваннях → Перевірка даних**.

## Перенесення прогресу

Прогрес зберігається в браузері конкретного пристрою. Щоб перенести його: **Налаштування → Експорт JSON** на старому пристрої, потім **Імпорт JSON** на новому.

## Озвучування

Для кнопки «Прослухати» потрібен український голос у системі. Якщо його немає, застосунок підкаже, як його додати; монолог можна прочитати вголос самостійно.
