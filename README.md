# СЛОВО 115

«Твій голос. Твоя впевненість».

Вебзастосунок для підготовки до усної частини іспиту з української мови: 115 тем, монологи рівня С1, тренування з таймером, режим іспиту та мовний тренажер. Працює на iPhone, Android і комп’ютері, після першого завантаження — без інтернету.

## Що всередині

- **Вивчити** — до кожної з 115 тем: формулювання, суть, зміст цитати чи метафори, план із 5 пунктів, монолог на 2–3 хв, коротка версія на 1 хв, 5 тез, корисні слова, типові помилки, 3 додаткові запитання, приклад із життя, озвучування.
- **Тренування** — 30 с підготовки з опорними пунктами, 3 хв відповіді, запис голосу (якщо браузер підтримує), текст відповіді, локальний аналіз за прозорими правилами, самооцінка, порівняння зі зразком, кнопка «Скопіювати для перевірки в Claude».
- **Іспит** — випадкова тема з усіх 115 (або лише зі складних і невивчених), без підказок; зразок відкривається тільки після завершення спроби.
- **Говори правильно** — кальки, прийменники, «це не помилка», наголоси, милозвучність, пароніми, логічні зв’язки, слова-паразити, висновок. Є режим «Перевір себе».
- Інтервальне повторення, статуси «Не знаю / Вчу / Знаю / Впевнено», обране, пошук, фільтри, тема дня, плани на 7/14/30 днів, навантаження 10/20/30 хв, історія, експорт та імпорт JSON, скидання прогресу.

Застосунок не оцінює вимову, наголоси й інтонацію і не імітує експертної перевірки. Прогрес, записи голосу й тексти відповідей залишаються на пристрої.

## Готовий пакет для існуючого репозиторію `Spartanetsd/115`

**Це спеціальна версія 1.0.1 для поточного репозиторію, де файли розташовані БЕЗ підпапок.**
В архіві всі файли лежать одразу в корені ZIP. Не створюйте `data`, `assets` чи `slovo115`.

1. Розпакуйте `SLOVO115_GITHUB_READY.zip` (на iPhone: «Файли» → торкнутися ZIP).
2. Перейдіть до [github.com/Spartanetsd/115](https://github.com/Spartanetsd/115).
3. Оберіть **Add file → Upload files**, додайте **всі файли з розпакованого архіву** (особливо `index.html`, `service-worker.js`, `manifest.webmanifest`, усі `content-*.js`, `topics.js`, `lang.js`, `app.js`, `style.css` та іконки) і натисніть **Commit changes**. Назви збігаються з існуючими — GitHub замінить файли.
4. Переконайтеся, що у **Settings → Pages** вибрано **Deploy from a branch → main → /(root)**.
5. Перевірте [spartanetsd.github.io/115/](https://spartanetsd.github.io/115/). Якщо Safari показує стару версію, відкрийте в приватній вкладці або очистьте кеш сайту.

**Увага:** не завантажуйте сам ZIP як файл у GitHub — GitHub Pages його не розпаковує. Потрібно завантажити файли *зсередини архіву*.

### Що виправлено

- Шляхи у `index.html` до 8 частин контенту, каталогу тем, мовного довідника та іконок тепер відповідають **наявній плоскій структурі репозиторію**.
- Шляхи у `service-worker.js` виправлено, кеш оновлено до `slovo115-v1.0.1`.
- Шляхи до іконок у `manifest.webmanifest` виправлено.
- Версію інтерфейсу оновлено до 1.0.1 без зміни місця зберігання прогресу.

### Структура ZIP — усе в корені

```text
index.html
app.js
style.css
content-01.js … content-08.js
topics.js
lang.js
service-worker.js
manifest.webmanifest
icon.svg, icon-180.png, icon-192.png, icon-512.png, icon-maskable-512.png
.nojekyll
README.md
```

### Як оновити контент надалі

Змінюйте потрібний `content-0N.js`; після нового оновлення підвищуйте `VERSION` у `service-worker.js` і у `app.js`. Для коректного GitHub Pages залишайте всі файли в корені репозиторію.

## Перенесення прогресу

Прогрес зберігається в браузері конкретного пристрою. Щоб перенести його: **Налаштування → Експорт JSON** на старому пристрої, потім **Імпорт JSON** на новому.

## Озвучування

Для кнопки «Прослухати» потрібен український голос у системі. Якщо його немає, застосунок підкаже, як його додати; монолог можна прочитати вголос самостійно.
